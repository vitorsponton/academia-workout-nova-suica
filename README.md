# Academia Workout - Nova Suíça

Este é o projeto completo do seu site, gerado e exportado pela plataforma Vitrune.

## 📁 Estrutura do Projeto

```
├── index.html       # Código completo do site (HTML5 + Tailwind CSS + Google Fonts)
├── vercel.json      # Configuração para deploy direto na Vercel
├── assets/          # Imagens e arquivos locais (quando aplicável)
└── README.md        # Instruções de publicação
```

---

## 🚀 Como Publicar na Vercel (Gratuito)

1. Acesse **[vercel.com](https://vercel.com)** e crie uma conta gratuita (se ainda não tiver).
2. No painel da Vercel, clique em **"Add New..."** → **"Project"**.
3. Se você exportou para o **GitHub**:
   - Conecte sua conta do GitHub e selecione o repositório deste projeto.
   - A Vercel detectará o projeto automaticamente como estático.
   - Clique em **"Deploy"**.
4. Se você baixou o arquivo **.zip**:
   - Abra https://vercel.com/drop e arraste o ZIP, sem descompactar.
   - Escolha o nome do projeto e clique em Deploy.
   - O index.html está na raiz. Não há package.json, instalação de dependências ou build.

As imagens locais estão em assets/. Imagens externas, Tailwind CSS e Google Fonts precisam de conexão à internet.

---

## 🌐 Como Publicar na Netlify (Alternativa Gratuita)

1. Acesse **[netlify.com](https://netlify.com)**.
2. Na aba **Sites**, arraste a pasta descompactada para a área **"Drag and drop your site output folder here"**.
3. Pronto! O site é publicado instantaneamente.

---

## 💻 Como Visualizar Localmente no Computador

Basta dar dois cliques no arquivo `index.html` para abri-lo diretamente em qualquer navegador (Google Chrome, Microsoft Edge, Safari, Firefox). Nenhuma instalação de software ou Node.js é necessária.
